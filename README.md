**1.O que são testes automatizados?**
	São procedimentos de validação e verificação de softwares executados de maneira automatizada por meio de frameworks e scripts. Desta forma, é necessário pouca ou nenhuma intervenção manual no processo de teste
**2.Por que são importantes?**
	Contribuem para a confiabilidade no software desenvolvido, assim como agilizam e facilitam o processo de testes, fazendo com que os testes sejam eficientes 
**3.Quando devem ser utilizados?**
	É ideal implementar a automação no começo do projeto, porém é possível integra-lá em qualquer fase do desenvolvimento após isso
